Setting up Shopify Collabs from zero (Shopify Help)

A. Store

  1. The SMTHG Shopify store needs a plan other than Starter or Retail.
  2. Shopify admin > Settings > Customer privacy: turn on Shopify Network Intelligence. Collabs requires it.

B. Install

  1. Open apps.shopify.com/collabs and click Install.
  2. Shopify admin > Apps > Collabs > Get started.
  3. Set the contact email. Influencers see it on every invite.
  4. Choose the product category, audience and creator country (US), then Finish setup.
  5. Settings > Point of contact: verify the email. Invites can't go out before this.

C. Brand profile

  1. Overview > Edit profile: logo, brand values, up to 4 images, and a description of how you work with creators.

D. Commission

  1. Programs > Create invite program.
  2. Commission: 20%. Set the link destination, then Create.

E. Payment settings

  1. Payments > Settings: holding period, default 30 days. You can set 1–90.
  2. Payments > Settings: turn on W-9 collection from US creators.

F. Invite

  1. Recruiting > Invite creators.
  2. Welcome offer: select the 20% program.
  3. Add each influencer's email, with a creator code if you want one.
  4. Write the message, add the Terms link, then Send invite.

G. After they accept

  1. Add each one to the 20% program. That creates their affiliate link and code.

Before Monday you need:

  • The Shopify store on an eligible plan.
  • Each influencer's email.
  • The Terms link.
